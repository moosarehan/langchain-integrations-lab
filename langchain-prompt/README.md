## 1. What are Prompts?

A **Prompt** is the text, instruction, or contextual input provided to a Large Language Model (LLM) or Chat Model to steer its output generation. In modern AI applications, prompts act as the main user interface and programming interface for guiding model reasoning and responses.

---

## 2. Importance of Prompts

Proper prompt design and engineering are essential for building reliable AI systems:
- **Steering Model Persona & Tone:** Defines background context, role constraints, and expected output style.
- **Reducing Hallucinations:** Gives clear instructions and fallback responses when information is insufficient.
- **Formatting Outputs:** Directs LLMs to respond in structured formats (JSON, Markdown, bullet points).
- **Consistency & Guardrails:** Enforces application boundaries and safety rules across multiple user inputs.

---

## 3. Static Prompts vs. Dynamic Prompts

### 🔹 Static Prompts
Static prompts are hardcoded text strings that do not change regardless of user input or application state.

```python
# Example of a static prompt
prompt = "Explain quantum computing in simple terms."
```

* **Pros:** Simple and easy to test for single-use cases.
* **Cons:** Rigid and non-reusable for varying user queries or dynamic workflows.

### 🔸 Dynamic Prompts (Prompt Templates)
Dynamic prompts use placeholders (variables) that are evaluated at runtime with custom user inputs or dynamic data.

```python
from langchain_core.prompts import PromptTemplate

template = PromptTemplate(
    template="Explain {topic} in simple terms for a {target_audience}.",
    input_variables=["topic", "target_audience"]
)

# Rendered dynamically at runtime
formatted_prompt = template.invoke({"topic": "Quantum Computing", "target_audience": "high school student"})
```

---

## 4. Why Prompt Templates over Python f-strings?

While Python `f-strings` (`f"Explain {topic}..."`) can insert variables into text, LangChain's **`PromptTemplate`** provides significant advantages:

| Feature | Python `f-strings` | LangChain `PromptTemplate` |
| :--- | :--- | :--- |
| **Reusability & Serialization** | Hardcoded in Python files; cannot be saved to JSON/YAML | Can be serialized to JSON/YAML (`template.save()`) and loaded across services |
| **Input Validation** | No validation; runtime `KeyError` if variables miss | Validates required input variables upfront (`validate_template=True`) |
| **Integration with LCEL** | Plain strings; cannot be chained natively | Natively integrates into LangChain Expression Language (LCEL) chains (`prompt \| model \| parser`) |
| **Partial Formatting** | Manual replacement needed | Supports partial formatting (`prompt.partial(domain="tech")`) |
| **Escaping & Security** | Prone to syntax conflicts with raw JSON braces `{}` | Handles double-brace escaping (`{{...}}`) safely for complex system prompts |

## 5. Messages in Multi-Turn Conversations

In chat-based applications, models process structured **Messages** rather than raw plain text. LangChain provides three core message types for multi-turn conversations:

1. **`SystemMessage`**: Sets background instructions, persona rules, and behavioral constraints for the AI model.
2. **`HumanMessage`**: Represents messages sent by the human user.
3. **`AIMessage`**: Represents responses generated by the AI assistant.

### Static Conversation Example (`messages.py` & `chatbot.py`)
```python
from langchain_core.messages import SystemMessage, HumanMessage, AIMessage

chathistory = [
    SystemMessage(content="You are a professional doctor."),
    HumanMessage(content="What are common symptoms of seasonal allergies?"),
    AIMessage(content="Common symptoms include sneezing, runny nose, and itchy eyes."),
    HumanMessage(content="How can I treat them?")
]
```

## 6. Dynamic Messages with `ChatPromptTemplate`

`ChatPromptTemplate` allows creating dynamic, structured chat prompts composed of system, human, and AI messages containing variables.

### Example (`chatprompttemplate.py`)
```python
from langchain_core.prompts import ChatPromptTemplate

# Constructing a dynamic chat prompt template
chat_template = ChatPromptTemplate([
    ('system', 'You are a helpful {domain} expert.'),
    ('human', 'Explain in simple terms, what is {topic}?')
])

# Formatting the template dynamically
prompt = chat_template.invoke({'domain': 'cricket', 'topic': 'Doosra'})
print(prompt)
```

## 7. MessagePlaceholders (`MessagesPlaceholder`)

When building chatbots, the length of the conversation history changes dynamically with every turn. **`MessagesPlaceholder`** allows you to inject a dynamic, variable-length list of chat messages into a prompt template seamlessly.

### Example (`messageplaceholder.py`)
```python
from langchain_core.prompts import ChatPromptTemplate, MessagesPlaceholder

# Chat template with dynamic chat history injection
chat_template = ChatPromptTemplate([
    ('system', 'You are a helpful customer support agent.'),
    MessagesPlaceholder(variable_name='chat_history'),
    ('human', '{query}')
])

# Sample chat history list
chat_history = [
    "HumanMessage(content='I want to request a refund for order #12345.')",
    "AIMessage(content='I can help with that. Is your item unused?')"
]

# Formatting with history + query
prompt = chat_template.invoke({
    'chat_history': chat_history,
    'query': 'Where is my refund confirmation?'
})
```
